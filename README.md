# WEEK1_PYTHON_ASSIGNMENT

## Personal Budget & Expense Tracker — Week 1

A static starter page for a personal budget tracker, built with plain HTML and CSS.

### Files
- `index.html` — semantic page structure, expense input fields, and empty expense-list placeholder.
- `style.css` — layout, colors, spacing, form styling, and responsive rules.

### Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

### Week 1 practice
- HTML headings, sections, labels, inputs, and select elements.
- Element, class, and ID CSS selectors.
- Browser DevTools: right-click the page and select **Inspect** to experiment with CSS.

**Note:** This is intentionally a static skeleton. The Add Expense button does not save or calculate expenses yet.
