# Personal Budget & Expense Tracker — Week 1

A static HTML and CSS skeleton for a personal budget tracker.

## Files
- `index.html` — semantic page structure, expense fields, and empty-state placeholder.
- `style.css` — element, ID, and class selectors plus responsive styling.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Right-click the page and choose **Inspect**. Change a CSS value in the Styles panel to practice using DevTools.

## Week 1 scope
This is a visual-only skeleton. The form does not save expenses or calculate totals yet; functionality can be added in later weeks.
